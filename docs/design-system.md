# Design System

## Library

```text
MUI (Material UI)
```

## Look

Quiet, gallery-like:

```text
White and grey

One accent colour

Artwork photos are the only strong colour on screen
```

## Accent Colour

```text
Deep museum red: #8B1E2D
```

## Dark Mode

Not in v1.

## Platform Rules

From `product-spec.md` under Platform. v1 targets desktop browsers; screens must:

```text
Resize to narrow widths

Not rely on hover, right-click or drag
```
